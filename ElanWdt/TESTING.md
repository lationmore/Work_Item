# 測試計畫（尚未執行）

## 建置

在具有 .NET Framework 4.7.2 Targeting Pack 的 VS2017 Windows 環境建置 Debug/Release。確認產生 EXE 及 EXE.config。AnyCPU 的 Prefer32Bit=false；32 位元程序的 Unicode detail cbSize 應為 6、64 位元應為 8，DevicePath 偏移均為 4。實際兩種程序架構的 interop 仍須分別驗證。

## 不執行硬體操作的 CLI 檢查

所有項目均從 **非管理員** 命令提示字元執行，並使用正確的預設設定檔。有效參數在管理員檢查失敗後返回 1，不應存取裝置或停止服務；不要改成提升權限執行此組檢查。

| 參數 | 預期 |
| --- | --- |
| `/?`、`/？`、`--help`（分別執行） | 0，僅顯示說明 |
| 無參數 | 1，要求管理員權限 |
| `/vid:04f3 /pid:0c8c` | 1，要求管理員權限 |
| `/VID:0x04F3 /PID:0X0C8C` | 1，要求管理員權限 |
| `/pid:0C8C` | 1，要求管理員權限 |
| `/vid:` | 2，空值 |
| `/vid:123` 或 `/vid:12345` | 2，長度錯誤 |
| `/vid:ZZZZ` | 2，非十六進位 |
| `/vid:04F3 /VID:04F3` | 2，重複參數 |
| `/foo:1234` 或 `/f:0` | 2，未知參數 |
| `vid:04F3` 或 `/vid` | 2，格式錯誤 |

設定檔檢查也只能在非管理員環境執行，先備份並於結束後還原：
- 刪除 VID key，不提供 CLI VID：預期 2。
- 刪除 VID key，提供 `/vid:04F3` 且設定檔 PID 有效：預期 1（已通過參數驗證）。
- 將 PID 設為非法字串，不提供 CLI PID：預期 2。
- PID 非法但用 `/pid:0C8C` 覆蓋：預期 1（已通過參數驗證）。
- XML 損壞且執行 `/?`：預期 0，help 不讀 appSettings。
- XML 損壞且無參數：預期 1，設定檔讀取失敗。

## 需授權測試裝置的人工驗證

以下不是自動測試，未執行；不可在日常使用或未知協定的裝置上測試：
- 無符合介面、或多個符合介面：應拒絕，且不停止 WbioSrvc。
- 服務停止失敗／逾時：不得送 WDT。
- 服務原本為 StopPending：應等到完全停止才送 WDT。
- CreateFile／DeviceIoControl 失敗：顯示原生錯誤並回傳 1，句柄釋放；服務不自動恢復。
- 支援原始協定的唯一目標：確認封包、IOCTL 與實機重置結果。呼叫成功不等於重置驗證通過。
- 測試完畢確認裝置健康，再依環境政策手動恢复 WbioSrvc。
